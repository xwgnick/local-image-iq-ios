# 方案 B 原生界面 · 0.5.0（build 13）

2026-09-29 用户选定白灰＋深青绿 B 方案，开始原生实现。**本页为待验证实现记录，不是已交付声明。** 已安装并确认成功的是 0.4.1 / build 12。

## 实现范围

- 主界面、图库和设置跟随系统浅／深色；正文与操作采用统一语义色。查看器仍为深色沉浸背景。
- 首页搜索直达、中文示例，图库状态改为底部精简入口。保留错误、权限和未完成准备的可见反馈。
- 全部结果使用规整双列 4:5，紧凑视图为三列方形；顺序仍完全由搜索结果决定，不显示视觉分数或排名徽标。
- **默认仍为前 3 张、地点权重 60%**；12 张仅为已有可选设置，不继承原型的示例默认值。
- 普通界面与照片权限说明统一中文；原始诊断状态保留原值，调试工具默认关闭且只在本次会话有效。
- 图库保留原生 Form、真实计数、暂停／继续、部分照片权限、错误恢复和明确的 iCloud 联网选择；没有后台准备、虚构 ETA 或新增自动重试。
- 翻译设置仍在普通设置中；实际英文查询与“使用原文”仍可用。系统键盘／分享面板遵循 iOS 语言设置，本轮不声称全语言本地化。

## 不变契约

不修改状态、模型、图像预处理、20 个图像 worker、HQ224 / Fast 回退、缓存身份、SQLite、排名、查询翻译引擎或网络策略。当前策略的有效索引无需重建；原账号／Bundle ID 覆盖安装，不卸载、不清库。

本地浏览器原型和公共示意照片未纳入原生资源或公开提交；原生截图只使用合成场景和未授权空状态。
