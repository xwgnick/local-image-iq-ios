## 实现

- 正常嵌入生产页面默认只保留一行“相似度”＋展开箭头；宽松范围说明只在展开时出现，删除确认警告保留。待处理状态合并为一条，**没有常驻“更新结果／重新分组”按钮**；独立测试宿主仍可保留旧按钮，不代表生产嵌入页。
- 可见、前台、就绪时自动恢复分组，缓存缺失／失效后自动计算。照片同步检查、写入、取消排空期间合并变化，结束后才进行一次最新请求；不每写一张图就重算。
- 滑杆拖动只改草稿，松手自动提交；无障碍增减直接提交。不添加任务截止时间或人为图库数量上限。
- 用户取消／失败不会因重复就绪通知自动重试；保留“继续／重试”。真实新来源事件、改变后松手的阈值可以请求新目标。
- 来源变化立即撤销旧结果授权、选择和删除意图；**仅索引变化**保留旧分组、详情浏览身份／会话和位置，新结果发布才授予新权限。真实Photos／授权／访问范围变化立即清除旧显示内容，不能把它与单纯索引变化混同。
- 详情从**左屏幕边缘向右滑**返回总览，短拖可取消；中部横向拖动仍用于选择照片。可见返回按钮保留。实现为UIKit屏幕边缘手势＋现有保留式总览，不是系统NavigationStack的interactive pop。清理主标签页没有虚构上一级；比较弹层没有新增边缘关闭。

## 性能边界

1. 完整输入未变时，复用**不可变、包括所有单张候选**的准备结果（向量、规范矩阵和norms）；完整复用键独立于阈值，阈值变化不重复JSON解码／重建矩阵。键包含完整授权元数据、图片BLOB摘要、模型、输入策略及算法；旧权限闭包不缓存。
2. 用原精确seed `sdot` 判定提前排除必然不能入组的候选，只排序可能通过的候选。排序仍用原 `mmul` 分数；后续所有成员的精确判定、组／成员顺序及最小相似度位模式不变。
3. 冷暖路径保留三次Photos完整快照与三次来源内容核验。**仍有每个种子的全N矩阵评分，最坏仍为O(N²D)，不是已完成“只算新增照片的局部分组”。**新增／删除可能改变规范贪心结果，不能直接拼接旧组冒充等价优化。

基准采用固定8000×768合成单张候选，冷阈值0.90、暖阈值0.75，各对比旧算法；小型96张dense分组另测真实临时SQLite服务。不设耗时通过门槛、没有新增benchmark跳过，不用测试总时长冒充分阶段提速，不把模拟器数据当真机速度。
