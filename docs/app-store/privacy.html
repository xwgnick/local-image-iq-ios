一、适用范围与运营者

本政策说明片刻寻如何在 iPhone、iPad 上处理照片及搜索相关信息，以及本支持网站和邮件联系渠道的信息处理方式。应用由个人开发者谢文戈运营，不提供账号注册或开发者运营的云端照片服务。

二、照片访问与本机处理

应用通过 Apple 照片权限读取你允许访问的照片，在本机进行图片特征计算、搜索、筛选和相似照片分组。你可以只授权部分照片，也可以在系统设置中调整或撤销权限。拒绝权限后，依赖照片的功能无法正常使用。

照片和搜索内容不上传到开发者服务器。应用没有广告、跨应用跟踪或开发者接收的自动分析上报功能。图像模型及分词资源随应用提供；运行时不从模型托管网站下载这些资源。

地点功能在本机使用照片已有的位置元数据和随包提供的离线行政区域数据，不通过定位服务获取你当前的位置，也不把照片坐标发送给在线地理编码服务。地点结果可能存在历史、范围或精度限制。

三、本机保存的信息与删除方式

  • 照片索引：保存搜索所需的图像特征、照片标识及相关索引信息，不在图片索引中保存原图或定位坐标。索引及相关缓存存储在应用的本机目录。
  • 文字索引：开启文字搜索后，系统 Vision 在设备上识别照片文字，识别结果保存在本机索引中。关闭文字搜索不会删除已保存的文字；使用“清除索引”可一并删除。识别文字可能包含身份证件、联系方式等敏感内容，请按需要开启。
  • 搜索记录：保存最近提交的搜索内容，用于显示最近搜索。可在“隐私与关于”中单独清除，不会删除照片或索引。
  • 偏好设置：保存你选择的文字搜索、翻译、清理阈值等设置，供下次使用。

图片／文字索引和搜索记录按应用实现排除系统备份；这不代表系统照片、所有偏好或 Apple 管理的数据均不备份。信息通常保留至你清除对应数据、系统清理缓存或卸载应用；“卸载 App”保留文稿与数据的系统操作不等于删除全部本机数据。

清除索引或搜索记录不会删除系统照片。撤销照片权限也不等于清除已经生成的本机索引；如希望删除，请使用相应清除操作。

四、Apple 系统联网服务

全局 iCloud 照片下载默认关闭。开启后，本地资源不足时，应用可请求系统下载照片资源。单张照片的“加载高清”在你明确同意后，也可仅下载该张照片，不会开启全局下载。数据流量和下载内容由系统决定。

中文搜索增强使用 Apple Translation；语言包准备可能需要联网，与 iCloud 下载开关独立。已准备的语言资源由系统管理，实际可用性取决于设备、系统版本和语言支持。

这些 Apple 服务适用其自身的设置和隐私政策。本应用不控制 Apple 的服务日志或保留期限。不能把“照片与搜索在本机处理”理解为设备绝不联网。

五、删除、相册操作与分享

收藏、相册管理及删除由你主动操作。相似照片清理不会自动删除照片；只有勾选并确认后才向系统提交删除。iCloud 照片可能将删除同步至其他设备，这与应用的预览下载开关无关。请确认选择，并保留重要照片的独立副本。

分享时，应用临时生成去除位置等源元数据的 JPEG，并在分享流程结束后清理临时文件。照片画面本身仍可能包含私人信息；接收方或你选择的分享服务可能保存副本，受其自身隐私规则约束。应用无法收回已发送的副本。

六、你的选择、支持与政策更新

你可以调整照片权限、关闭文字搜索或可选系统下载、清除搜索记录与索引，或删除应用。应用不提供账号，因此没有账号注销流程。

如通过上述邮箱主动联系开发者，开发者将收到你发送的邮箱地址、邮件正文及附件，仅用于回应和处理你的请求。邮件会通过你与开发者使用的邮件服务处理；该渠道使用网易163邮箱，邮件服务自身的数据处理适用其规则。请勿发送身份证件、私人照片、完整照片库、索引数据库或 Apple 密码。

支持邮件及附件将在问题处理完毕后90天内从开发者控制的邮箱中删除，开发者会定期清理。尚在处理的请求，或法律要求保留、处理相关争议确有必要保留的信息，仅在必要范围和期限内保留；保留理由消失后及时删除。此规则不代表开发者能够删除发件人或邮件服务商独立保存的副本。

如果你希望了解、更正或删除已通过支持渠道提交的信息，可以发送邮件提出请求。请不要为了验证身份而主动发送身份证照片；开发者仅在处理请求必要时核实相关信息。本机照片、索引及搜索记录的管理方式见本政策第三节，开发者无法远程读取或删除这些本机数据。

如果后续版本改变数据处理方式，本政策将同步更新。新增数据上传或其他需要授权的处理，不会仅凭本页更新替代必要的告知与同意。

七、本网站的托管与访问记录

隐私与支持页面使用 GitHub Pages 托管。页面不包含统计脚本、广告、反馈表单或第三方字体；但访问网页时，GitHub 会为安全目的记录和保存访问者的 IP 地址。网站托管不用于上传或存储你的照片库、搜索记录及索引。

托管服务的数据处理和保存规则由 GitHub 管理，详见GitHub 隐私声明。应用的本机处理与打开外部网页是不同的数据处理场景；访问网站不代表你的照片或查询会被发送给开发者。
