# 自动增量同步与简约清理页 — 0.12.0 / build 33

## 当前：实现完成，原生验证与交付待完成

用户已批准本轮全部设计：清理V3折叠滑杆、默认0.90、组按最新／大小排序，以及同步V2底部进度和取消。沿用build32的1550可信系统路径修复。此页记录实现边界，测试／IPA交付结果须在真实验证后补充，不把编辑器诊断当成原生通过。

## 清理页面

- 单一标题，介绍「找出相近的照片，方便挑选和清理。」；后接「可手动调节组内照片相似度的严格程度。」和44点下拉箭头。默认收起，只有点箭头展开。
- 展开后左「宽松」、中「组内照片相似度」、右「严格」。滑杆仍为0.50–0.99，步长0.01；两位实时数值在下方正中，11点常规灰色字体。设置不再重复放滑杆。
- 无有效偏好时默认0.90；原有有效偏好全部保留，包括用户选择过的0.80。旧版本未记录0.80的来源，不能擅自覆盖有效选择。仅点击「更新结果」应用并持久保存草稿；拖动不计算、不取消正在完成的旧参数分组、不清旧结果。
- 草稿变化时保留旧组供浏览，显示旧结果应用值，禁止用未更新选择删除；点击更新后清选择并计算一次。有效零组也支持待更新提示。
- 展示顺序：每组最新照片的creation时间降序，其次照片数量降序，再用组ID稳定打破平局；全无时间的组排最后。不用修改、索引或运行时间。算法／缓存仍使用原有规范顺序，只投影到显示层，组内成员及两两阈值判定不变。
- 去除组总览常驻最低分、零选择计数和重复预览计数；超过30张封面样本时提供查看全部。五列组内浏览、对比、滑动选择与系统删除确认保留。

## 自动图片索引同步

- 成功完成启动准备且已有可读Photos授权后，独立同步任务检查当前授权范围，增量处理新增／版本变化／旧模型或缺失向量的照片，保留未变化的有效向量。无权限时不自动请求授权，不以空枚举删除索引。
- 使用已有HQ224回退、用户网络选择、同一模型和20路图片编码槽。前台搜索worker与同步worker分离，显式共享主编码器／text／tokenizer；同一时刻只运行一项图片维护作业，避免自动与手动索引同时加载两套20路池。
- 清理的是App图片索引及无引用地点向量，**不自动删除系统照片**。Limited授权缩小只意味着不可访问，不在UI冒充真正删除了照片。撤权、代际变化和完整revision变化在提交前及事务内再次校验，失败回滚未提交工作。
- 每个成功提交后刷新真实落盘计数，新图片无需等整轮结束就可开始搜索。独立计数刷新不清空当前查询、排名、选择或分页会话；取消后的已提交索引继续可用。计数失败不伪造零，也不以encoded-minus-removed推算。
- 自动图片同步**不自动执行OCR**。旧OCR不能用于不匹配revision／不可访问照片，文字索引仍为显式建立／更新。
- 背景切换取消并排空当前工作，回前台重新核对差异；不保证iOS后台常驻、关闭App后继续编码。

## 并行与一致性

- 自动同步不占用前台操作的busy状态，搜索、浏览、切页可用，编码准备不持数据库写锁；单张记录发布才短暂取得写租约。
- 为保留完整源监视和发布前校验，搜索、OCR、诊断及一次清理恢复／计算持有读租约直到相应结果发布。同步可以同时准备向量，但提交会等待正在读取的操作完成；长分组／OCR会推迟这段提交，不宣称所有数据库操作无等待或性能零影响。
- 显式手动索引／清空／重建仍走原前台串行入口，先排空自动同步，再取得写租约；这不是第二个自动作业。当前没有将旧手动维护改为所有操作无条件并行。
- 索引写入前推进协调器版本，旧清理选择立即失效；实际提交或失败／取消结算均传播版本变化，但失败不冒充提交。旧组仅供浏览，手动更新先尝试有效缓存的新验证器，否则才重新分组。
- 保留NOFOLLOW、可信系统路径解析、DELETE日志模式、sidecar、reserved writer、data_version及PhotoKit完整验证；不引入WAL、schema迁移、任意容量限制或全任务超时。不声称消除跨Photos／SQLite／文件系统的全部竞态。
- 同时修复旧手动索引的撤权空枚举清库缺口，并让手动保存使用事务内完整revision校验。用户明确确认的清空／重建仍是单独操作。

## 底部同步卡与取消

- 两主页面共用轻量黑金卡片和3点细进度。检查总量未知时只显示阶段，更新时显示真实处理数；网络缺图与失败分别计数，不当作全部成功。
- 右侧「取消」至少44×44。先停止派发并请求取消，等待不能即时终止的预测返回时显示「正在取消…」，真正排空后才显示「同步已取消」。已提交记录不回滚、不清库，也不取消用户已提交的系统Photos删除。
- 本次用户取消持续到显式「重新同步」或下一次进程冷启动，切页／普通刷新不立即重启。重新同步重新读取差异，不复用旧删除清单。
- 正常完成提示约3秒后收起，该时间只控制提示显示，不是同步期限。取消／失败／需联网提供手动重启；弹层或键盘出现时隐藏基础同步卡，任务本身不因隐藏被取消。底部安全区为卡片、选择工具栏和主导航让位。
